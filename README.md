# 🐞 BUGGAMES — Anti Gabut Club

**61 mini game seru** bareng Buggy si maskot bug! PWA offline-first untuk Android: buka → tap → langsung main. Gratis, tanpa iklan, tanpa akun.

## 🎮 Isi

- 🕹️ **Arcade** — Ular Bug, Breakout, Pong, Flappy Bug, Bug Space Raid, Pukul Bug, Balon Pop, Bug Dodge, Lari Bug, Tangkap Bug, Stack Tower, Penalti Bug, Panahan Bug, Asteroid Bug, Lintas Jalan
- 🧩 **Puzzle & Logika** — Tiga Serangkai, Sambung Empat, Bom Bug, Lights Out, Geser Angka, 2048 Bug, Labirin Bug, Menara Hanoi, Sudoku Mini, Tebak Kata, Kapal Bug, Dots and Boxes, Kehidupan Bug
- ❓ **Kuis & Kata** — Cocokkan Bug, Simon Bug, Refleks Bug, Latih Bidik, Math Sprint, Kuis Buggy, Tebak Kata, Huruf Hilang, Susun Kata, Uji Ketik, Tebak Angka, Lebih Tinggi?, Cari yang Beda, Angka Terbesar, Warna vs Kata, Hitung Bug, Batu Gunting Kertas, Duel Dadu, Tebak Koin, Bug Clicker, Cari Bug!, Tap Warna!, Klik Tercepat!, Deret Angka
- 🏎️ **3D** — Balap Mobil 3D, Drifting Mobil 3D, Jelajah Hutan 3D, Rally Hutan 3D, Balapan Sepeda 3D, Safari 3D, Free Ride 3D, Jungle Run 3D, **Helikopter 3D**

Semua game berbeda, tanpa duplikat. Skor terbaik tersimpan di perangkat.

## 📱 Install di Android

1. Buka `https://rafieakila-cloud.github.io/buggames/` di Chrome Android
2. Menu ⋮ → **Install app / Tambahkan ke layar utama**
3. Mainkan — bisa offline penuh!

## 🛠️ Teknologi

Murni HTML/CSS/JS + Canvas, tanpa framework/build. Pseudo-3D engine (OutRun-style) untuk game balapan & heightfield 3D untuk Helikopter 3D. Service worker untuk offline. Maskot & ikon SVG custom.

Push ke branch `main` otomatis ter-deploy ke GitHub Pages via GitHub Actions.
